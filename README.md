# FreshPal Smart Sensor

A custom-built smart refrigerator sensor that monitors temperature and detects
early spoilage via ammonia gas sensing, built around an ESP32-S2 with a
fully custom PCB designed in Altium Designer.



<img width="1066" height="575" alt="Freshpal" src="https://github.com/user-attachments/assets/d0145421-bd47-4027-8c2a-0ead6c7587f7" />
## Features
- Real-time temperature monitoring (DS18B20)
- Spoilage/ammonia gas detection (SPEC Sensors 3SP_NH3_1000 electrochemical
  sensor + TI LMP91000 analog front-end)
- Wireless connectivity via ESP32-S2
- USB-C rechargeable battery power with on/off switch and BLE pairing button

## Hardware
- Custom 2-layer PCB, designed and routed in Altium Designer
